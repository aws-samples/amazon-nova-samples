# Amazon Nova Act - エージェント型ワークフロー

Amazon Nova Act は、Web ブラウザ内で確実にアクションを実行できるエージェントを構築するために設計された Python SDK とモデルの、初期リサーチプレビューです。このリポジトリには、Nova Act を現実的なエージェント型ワークフローへどう適用できるかを示す実践的な実装とユースケースが含まれています。

## Nova Act とは

Nova Act により、Web アプリケーションと自律的にやり取りできるインテリジェント エージェントを開発できます。壊れやすいスクリプトベースの自動化に依存する従来手法とは異なり、Nova Act のエージェントは次のことができます。

- **観察して適応する**: UI 変更に動的に対応
- **賢く判断する**: コンテキストとユーザー意図に基づく意思決定
- **複雑なワークフローを実行する**: 信頼できるコマンドへ分解して処理
- **Python コードと自然に統合する**: テスト、アサーション、デバッグに活用可能

この SDK は **Amazon Bedrock AgentCore Browser** と連携して動作します。これは安全なクラウドベースのブラウザ実行環境であり、次を提供します。

- セッション分離とセキュリティ
- 組み込みの可観測性（ライブビュー、CloudTrail ログ、セッションリプレイ）
- コンテナ化されたエフェメラル環境
- 並列実行向けの同時ブラウザ セッション対応

## ユースケース

このリポジトリでは、エンタープライズ ワークフロー向けの Nova Act 実装例を紹介しています。

### 🧪 [Agentic QA Testing](./usecases/qa-testing/)

Nova Act と AgentCore Browser を使って、Web アプリケーションの品質保証テストを自動化します。このユースケースでは次を示します。

- **インテリジェントなテスト実行**: 壊れやすいセレクタに依存せず、UI 変更に適応
- **並列テスト実行**: 複数ブラウザ セッションで高速にフィードバック
- **JSON 駆動のテスト定義**: 非技術者でもテストを作成可能
- **リアルタイムな可観測性**: ライブブラウザ表示とセッションリプレイ
- **pytest との統合**: 包括的なテストレポートと CI/CD パイプラインに対応

**主な利点:**

- テスト保守コストを 40-60% 削減
- 包括的なテストスイートを数時間ではなく数分で実行
- UI 変更による誤検知を削減
- ブラウザ、デバイス、環境をまたいだテストを容易にスケール

**含まれる内容:**

- テスト用のサンプル小売 Web アプリケーション
- すぐ使える 15 個の JSON テストケース
- 並列実行対応の pytest フレームワーク
- AWS デプロイ用 CloudFormation テンプレート
- 完全なセットアップおよびデプロイ手順

[→ Explore the QA Testing Use Case](./usecases/qa-testing/)

### 💰 [Price Comparison](./usecases/price_comparison/)

Nova Act を使い、複数の小売業者間で商品価格比較を自動化します。このユースケースでは次を示します。

- **インテリジェントな商品検索**: 小売サイトを巡回し、該当商品を発見
- **並行実行**: 複数小売業者を同時検索して価格発見を高速化
- **構造化データ抽出**: Pydantic スキーマによる信頼できる価格情報取得
- **Captcha 対応**: 必要時に手動介入を促すユーザープロンプト
- **CSV 出力**: 結果を分析・比較しやすい形式で保存

**主な利点:**

- Amazon、Best Buy、Costco、Target などを数分で横断比較
- ブラウザ操作自動化により手作業の価格確認を削減
- 商品名、価格、プロモーション詳細を構造化して取得
- CLI 引数で商品 SKU や小売業者を簡単にカスタマイズ

**含まれる内容:**

- すぐ実行できる価格比較スクリプト
- カスタム商品 SKU および小売業者指定対応
- 抽出価格向けの Pydantic ベース検証
- 小売業者検索の並列化に ThreadPoolExecutor を使用
- 完全なセットアップおよび利用手順

## なぜエージェント型ワークフローなのか

従来の自動化アプローチには次の課題があります。

- **保守コストが高い**: UI 変更でスクリプトが壊れ、継続的な修正が必要
- **スケーラビリティが低い**: 手動テストは時間がかかり、網羅性も不足しがち
- **技術的な障壁**: 自動化作成には専門的なプログラミング知識が必要
- **壊れやすい**: 特定のセレクタ依存で、コンポーネント変更に弱い

Nova Act を使ったエージェント型 AI は、これらの課題に次のように対処します。

- **動的に適応**: 手動更新なしでインターフェース変更に追従
- **人間らしい操作を模倣**: より現実的なテストを実現
- **非技術者でもテスト作成可能**: シンプルな JSON 定義で対応
- **柔軟な経路で広くカバー**: 固定スクリプトに縛られない
